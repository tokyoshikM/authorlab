# Метод проверки

Проект использует публичный HTTP-сервис [k1y0mi/ru-ai-text-detector](https://huggingface.co/spaces/k1y0mi/ru-ai-text-detector). [Исходный проект](https://github.com/k1y0miiii/ru-ai-text-detector) публикует API `POST /detect`. В запросе закреплена версия `v4`:

`https://k1y0mi-ru-ai-text-detector.hf.space/detect?model=v4`

Сервис размещён третьей стороной. Его доступность, изменения, квоты и правила обработки данных не контролируются владельцем АвторLab. При интеграции проверены ответ API и CORS для GitHub Pages. Гарантии постоянной доступности публичной демонстрации не получены.

## Вычисления

По исходному коду провайдера v4 — дообученный `ai-forever/ruBert-base`, с изотонической калибровкой выходной оценки и отдельным порогом для коротких фрагментов. Метод `proba` использует токенизацию с `truncation=True` и `max_length=256`, включая служебные токены. Следовательно, длинные стихотворения оцениваются по началу; сайт сообщает об этом до отправки текста.

API возвращает `ai_probability`, `threshold`, `verdict` и `model`. Сайт проверяет типы, диапазоны, версию и допустимый вердикт. Отображаемый вывод учитывает вердикт сервера: он может зависеть от порога, отличающегося от 50%. Если серверный вердикт указывает на класс, которому соответствует оценка меньше 50%, сайт показывает неоднозначный результат. Это правило осторожного отображения, а не новый обученный порог. Исходные проценты сохраняются. На границе округления сайт не заменяет серверный вердикт на противоположный. Оценка второго класса отображается как дополнение до 100%. Эти числа не обозначают долю сгенерированных строк.

Собственные модельные веса в этой версии не распространяются. Обучение не выполнялось в рамках интеграции.

## Передача данных

После явного нажатия кнопки браузер отправляет только JSON с полем `text` на сервер провайдера. API-ключ и учётная запись посетителю не требуются на момент интеграции. Запросы выполняются без учётных данных браузера и без автоматического переключения на другой сервис. Утверждение о том, что провайдер не сохраняет текст или другую информацию, сайтом не делается.

Литературный разбор выполняется локально. Известные литературные совпадения не меняют сетевую оценку и не заменяют её на 0% или 100%.

## Ошибки

Общий тайм-аут — 180 секунд. Ответы 502, 503 и 504 допускают одну повторную попытку с паузой. Лимит 429 и ошибки формата не запускают повторные циклы. Некорректный JSON, неподдерживаемая версия и значения вне допустимого диапазона отклоняются. При уходе с экрана браузер отменяет запрос и не вставляет запоздалый результат в другой раздел.

## Ограничения

Качество на русской поэзии должно оцениваться отдельно. Смена способа запуска не является доказательством улучшения качества. Короткие фрагменты, стилизация, редактирование и смешанное происхождение могут приводить к ошибкам. Числа из документации провайдера не являются результатом независимой проверки сайта. Программные тесты проверяют интеграцию, а не способность достоверно устанавливать авторство.
